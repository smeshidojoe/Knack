# Knack

Выезжающая панель для Windows: медиаконтроль, полка скриншотов, история буфера,
заготовки, переводчик. Идея и раскладка вдохновлены
[cyclop](https://github.com/akalikbergenov/cyclop) — только там чёлка MacBook, а
здесь плашка выезжает из свободного края экрана.

## Запуск

```bash
pip install -r requirements.txt
```

```bash
python main.py
```

Панель появляется при наведении курсора на край экрана (противоположный панели
задач) и по хоткею `Ctrl+Alt+K`. Значок — в трее.

## Что уже есть

- Окно панели: выезд из свободного края, скрытие по уходу курсора, `WS_EX_NOACTIVATE`
  (фокус активной программы не сбивается), скруглённые углы, автоопределение края
  через `SHAppBarMessage`.
- Масштабирование: макет нарисован под 2560x1440, коэффициент задан двумя
  опорными точками в `knack/core/scale.py` и считается от ВЫСОТЫ экрана —
  1080p даёт x1.25 (718x240), 1440p x1.4548 (835x279), 4K x1.8644 (1070x358).
  Поверх идёт множитель `ui_scale` (ползунок размера в настройках). Панель
  открывается на том мониторе, где курсор, и туда же уезжает при закрытии,
  даже если мышь успела уехать на соседний.
- Анимации на своих часах (`knack/ui/anim.py`) с частотой монитора: на 180 Гц
  выезд идёт в 180 к/с, а не в 60, как у QPropertyAnimation. Настройка
  `animation_fps` позволяет прибить частоту к 60 на слабых машинах.
- Вкладка «Музыка»: обложка, название, исполнитель и альбом, источник звука,
  анимированный эквалайзер, кнопки назад/пауза/вперёд, полоса перемотки с
  превью позиции под курсором. Данные — из Windows Media Session (SMTC), опрос
  идёт только пока вкладка открыта, а позиция трека двигается своими часами.
  Источников может быть несколько (браузер + плеер): клик по названию источника
  в правом верхнем углу переключает между ними.
- Вкладка «Полка»: сетка карточек, скриншоты из буфера и файлы, брошенные на
  панель. Картинка показывается превью, у медиафайла в буфер уходит путь.
- Вкладка «Буфер»: история скопированного текста, клик возвращает строку в
  буфер, лимит `clipboard_limit`. Следим за буфером по событию системы, без опроса.
- Вкладка «Сниппеты»: поиск по имени и значению, плюс справа добавляет запись.
- Вкладка «Заметки»: список слева, текст справа, заголовок — первая строка.
- Вкладка «Переводчик»: две панели, выбор языка по клику на подпись, перевод
  через паузу после набора.
- Вкладка «Настройки»: язык, размер панели, частота анимаций, способ открытия и
  скрытия, сочетание клавиш (ловится нажатием), монитор, отступ от края, длина
  истории буфера, движок перевода с полем ключа DeepL, автозапуск. Всё
  применяется сразу и тут же пишется в конфиг.
- Вкладки в колонке слева растут при наведении вместе с подсветкой и поджимаются
  при клике; «Заметки» вынесены отдельной кнопкой к правому краю, как в макете.
- Глобальный хоткей, трей со своим контекстным меню в теме программы,
  автозапуск, конфиг в `%APPDATA%\Knack\config.json`. Второй экземпляр не
  запускается (именованный мьютекс). `Ctrl+C` в консоли закрывает программу
  штатно: настройки сохраняются, хоткей снимается, поток медиа останавливается.
- Два языка интерфейса (`knack/core/i18n.py`), переключение — `language` в конфиге.
- Темы: цвета вынесены ролями в `knack/ui/theme.py`, первая тема собрана из макета.

## Чего ещё нет

- Бэкенды перевода не входят в зависимости: `pip install argostranslate` для
  офлайна либо ключ DeepL в `deepl_key`. Без них вкладка честно пишет, что
  переводчик не настроен.
- Превью кадра у видео на полке: нужен ffmpeg, пока рисуется значок файла.

## Где лежат данные

Всё в `%APPDATA%\Knack`, переживает перезапуск программы и системы:

| Файл | Что внутри |
|---|---|
| `config.json` | настройки |
| `clipboard_history.json` | история скопированного текста (лимит `clipboard_limit`) |
| `shelf.json` | карточки полки: имена файлов, пути к медиа, время |
| `clipboard/` | сами картинки полки, по файлу на карточку |
| `snippets.json` | сниппеты; правится и руками |
| `notes.json` | заметки |
| `knack.log` | лог |

Запись атомарная: содержимое пишется во временный файл рядом и подменяет
целевой, поэтому обрыв на середине не оставит пустой файл вместо всех данных.

## Структура

```
main.py                 точка входа
knack/
  app.py                сборка: настройки, службы, панель, трей, хоткей
  tray.py               значок в трее
  core/
    constants.py        пути, координаты макета
    config.py           настройки (%APPDATA%\Knack\config.json)
    scale.py            масштаб от ширины экрана
    fonts.py            SF Pro Display
    icons.py            загрузка и перекраска иконок
    taskbar.py          где панель задач
    hotkey.py           RegisterHotKey + фильтр сообщений
    i18n.py             строки интерфейса (ru/en)
    jsonfile.py         чтение и запись файлов данных
    autostart.py        запуск с Windows
    logbook.py          лог в %APPDATA%\Knack\knack.log
  services/
    hub.py              сборка всех служб
    media.py            Windows Media Session
    clipboard.py        слежение за буфером обмена
    shelf.py            файлы полки
    snippets.py         сниппеты
    notes.py            заметки
    translate.py        Argos / DeepL
  ui/
    theme.py            цвета ролями
    anim.py             общие часы анимаций
    menu.py             меню в стиле панели
    overlay.py          окно панели, анимация, слежение за курсором
    tabbar.py           левая колонка вкладок
    pages/              вкладки
    widgets/            обложка, эквалайзер, полоса перемотки, списки, поля,
                        переключатели и ползунки настроек
assets/
  app.ico               иконка приложения (для трея и будущего exe)
  fonts/                SF Pro Display
  icons/                иконки (SVG из Figma + PNG)
```

## Заметки

- `.env` с `FIGMA_TOKEN` в `.gitignore` — в репозиторий не попадёт.
- Медиа работает через проекции `winrt-*`, а не `winsdk`: у последнего под
  Python 3.13 нет готовых колёс, сборка требует MSVC.
