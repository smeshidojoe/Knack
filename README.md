# Knack

Выезжающая панель для Windows: медиаконтроль, полка скриншотов, история буфера,
заготовки, переводчик. Идея и раскладка вдохновлены
[cyclop](https://github.com/akalikbergenov/cyclop) — только там чёлка MacBook, а
здесь плашка выезжает из свободного края экрана.

## Запуск

```bash
pip install -r requirements.txt
```

```bash
python main.py
```

Панель появляется при наведении курсора на край экрана (противоположный панели
задач) и по хоткею `Ctrl+Alt+K`. Значок — в трее.

## Что уже есть

- Окно панели: выезд из свободного края, скрытие по уходу курсора, `WS_EX_NOACTIVATE`
  (фокус активной программы не сбивается), скруглённые углы, автоопределение края
  через `SHAppBarMessage`.
- Масштабирование: макет нарисован под 2560x1440, коэффициент задан двумя
  опорными точками в `knack/core/scale.py` — 1440p даёт x1.15 (660x221), 1080p
  x1.25 (718x240). Чем меньше экран, тем крупнее плашка. Панель открывается на
  том мониторе, где курсор.
- Вкладка «Музыка»: обложка, название, исполнитель и альбом, источник звука,
  анимированный эквалайзер, кнопки назад/пауза/вперёд, полоса перемотки.
  Данные — из Windows Media Session (SMTC), опрос идёт только пока вкладка открыта.
- Глобальный хоткей, трей, автозапуск, конфиг в `%APPDATA%\Knack\config.json`.
  `Ctrl+C` в консоли закрывает программу штатно: настройки сохраняются, хоткей
  снимается, поток медиа останавливается.
- Темы: цвета вынесены ролями в `knack/ui/theme.py`, первая тема собрана из макета.

## Чего ещё нет

Вкладки «Полка», «Буфер», «Заготовки», «Переводчик» и «Настройки» — заглушки
(`knack/ui/pages/stubs.py`), ждут макета. Переводчик планируется на Argos
(офлайн) с переключением на DeepL по ключу.

## Структура

```
main.py                 точка входа
knack/
  app.py                сборка: настройки, службы, панель, трей, хоткей
  tray.py               значок в трее
  core/
    constants.py        пути, координаты макета
    config.py           настройки (%APPDATA%\Knack\config.json)
    scale.py            масштаб от ширины экрана
    fonts.py            SF Pro Display
    icons.py            загрузка и перекраска иконок
    taskbar.py          где панель задач
    hotkey.py           RegisterHotKey + фильтр сообщений
    autostart.py        запуск с Windows
    logbook.py          лог в %APPDATA%\Knack\knack.log
  services/
    media.py            Windows Media Session
  ui/
    theme.py            цвета ролями
    overlay.py          окно панели, анимация, слежение за курсором
    tabbar.py           левая колонка вкладок
    pages/              вкладки
    widgets/            обложка, эквалайзер, полоса перемотки, кнопки, текст
assets/
  fonts/                SF Pro Display
  icons/                иконки (SVG из Figma + PNG)
```

## Заметки

- `.env` с `FIGMA_TOKEN` в `.gitignore` — в репозиторий не попадёт.
- Медиа работает через проекции `winrt-*`, а не `winsdk`: у последнего под
  Python 3.13 нет готовых колёс, сборка требует MSVC.
